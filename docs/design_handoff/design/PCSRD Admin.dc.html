13 — ADMIN CMS ARABIC ONLY · RTL · force-dynamic · noindex

The admin is Arabic-only, as specified: the staff who use it work in Arabic, and a bilingual admin doubles the surface for no gain. The content inside it is still bilingual — that is a different axis, and it is carried by one component, the bilingual field, which shows both locales side by side with the correct dir per input.

Two visual departures from the public site, both deliberate. Density goes up — this is a tool, not a document, and a content manager scanning forty projects needs rows, not cards. And shadow is permitted here on genuinely floating layers (dialog, sheet, dropdown), which the public site never has.
